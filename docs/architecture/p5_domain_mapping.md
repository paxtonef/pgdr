## Reading this table honestly

10% MAPPED is not a shortfall to apologize for — it's the accurate
reflection of how much genuine, sourced automotive evidence-reasoning
existed to port as of P5. The mandate's own instruction (§9) is explicit:
inventing 200 "plausible" relations to inflate this number would be worse
than leaving 8 questions NEUTRAL. Every NEUTRAL question still reaches the
report as a recorded observation — it simply doesn't (yet) move any
hypothesis's confidence, and nothing in the product's behavior claims that
it does.
